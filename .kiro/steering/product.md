# TailorTalk — Product Overview

TailorTalk is a conversational AI agent that helps users search, filter, and discover files
within a designated Google Drive folder using natural language.

## Core Value

Users ask questions like *"find the budget PDF from last month"* and get accurate results
presented as clickable file cards — no manual Drive searching required.

## Key Features

- Natural language search by name, file type, content, and date
- Conversational follow-up queries ("show me only PDFs of those")
- Fallback query relaxation — 3 progressive levels when zero results are returned
- File result cards with direct Google Drive preview links
- Multi-turn conversation memory within a session
- Suggested query buttons for first-time users

## Target Users

Developers and evaluators testing the TailorTalk assignment submission via a live Streamlit URL.
